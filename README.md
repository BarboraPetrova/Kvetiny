# Květiny — pokojovky pro Obsidian

Poznámky o péči o pokojové rostliny + canvas a obrázky.

## Stažení
**Code → Download ZIP** a rozbalit (nebo `git clone https://github.com/BarboraPetrova/Kvetiny.git`).

## Zprovoznění v Obsidianu
Zkopíruj celou složku **`Květiny`** do **kořene svého vaultu**.
> Důležité: dej ji do kořene (ne do podsložky), jinak canvas nenajde svoje poznámky a obrázky.

## Filtrování podle vlastníka
V canvasu jde rostliny **filtrovat podle vlastníka** (property `owner`) — přepínáš tak, čí rostliny se zobrazí.

## Poznámka
Obrázky ve `img/` musí mít stejný název jako v poznámce (např. `Monstera.png`). Poznámky jsou běžné Markdown soubory, klidně je uprav nebo přidej vlastní.
